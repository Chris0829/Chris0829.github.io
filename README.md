# Zhenghao Chen's Academic Homepage

Personal academic homepage of **Zhenghao Chen (陈峥浩)** — Master's student in Information and Communication Engineering at the Hangzhou Institute of Technology, Xidian University. Research: graph neural networks, multimodal recommender systems, and urban climate resilience.

- 👤 GitHub: [github.com/Chris0829](https://github.com/Chris0829)
- 📧 Email: zjzjczh@163.com
- 📍 Hangzhou, China

## Features

- **Markdown-driven, no build step** — content is fetched from `contents/*.md` and rendered client-side.
- **Bilingual (EN / 中文)** with a navbar toggle; **English is the default**.
- Background image slideshow, responsive layout, collapsible "Details" blocks for research entries, and MathJax support.

## Content layout

| File | Purpose |
| --- | --- |
| `contents/config.yml` | Title, tagline, sections, nav, backgrounds, footer links (English) |
| `contents/*.md` | English section content (home, news, research, publications, awards, service) |
| `contents/zh/config.yml` | Chinese config |
| `contents/zh/*.md` | Chinese section content |
| `static/assets/img/photo.png` | Profile photo |
| `static/assets/background/*.jpeg` | Background slideshow images |
